# Google Sheets API Integration

A Spring Boot application that connects to the Google Sheets API using a Google Cloud service account and reads data from a Google Spreadsheet.

The application reads data from the configured spreadsheet and prints the rows to the console.

---

## Prerequisites

Make sure the following are installed:

- Java 17 or higher
- Maven 3.8+ (or use the included Maven wrapper)
- A Google Cloud account
- A Google Cloud service account with access to the Google Sheets API
- Access to the target Google Spreadsheet

---

## 1. Clone the Repository
git clone https://github.com/yash-agarwal12/Google-Sheets-API-Integration.git 

## 2. Checkout to dev branch

## 3. Add Google Service Account Credentials
The Google service-account credentials are not included in this repository for security reasons.
Each user who wants to run this application must provide their own Google Cloud service-account JSON credentials.
Add it to the resource folder
